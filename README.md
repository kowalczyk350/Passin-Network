# Passing-Network
🇪🇸 TACTICAL ANALYSIS | Real Madrid – Liverpool (UCL Final 2018) | Passing Network

🏆 Match: Real Madrid – Liverpool 3:1
📅 May 26, 2018 | Olympic Stadium, Kyiv
👤 Author: M. Kowalczyk | Scout at Jagiellonia Białystok

ANALYSIS OBJECTIVE

To examine Real Madrid's passing structure in the 2018 Champions League final. I used StatsBomb Open Data (3,497 match events) and custom Python code to generate a passing network.

KEY STATISTICS

🔹 533 passes between Real Madrid players (87.4% completion rate)
🔹 11 active players (entire starting XI)
🔹 Average passes per player: 48.5

TOP 5 PASSING DUOS

1️⃣ Ramos → Marcelo – 23 passes
2️⃣ Varane → Ramos – 21 passes
3️⃣ Marcelo → C.Ronaldo – 20 passes
4️⃣ Marcelo → Benzema – 19 passes
5️⃣ Ramos → Kroos – 16 passes

TACTICAL CONCLUSIONS

🧠 Left side as the driving engine – Marcelo and Ramos key figures
🎯 Toni Kroos – the brain of the team (connects defense to attack, appears in 5 of the top 10 passing duos)
⚡ C.Ronaldo and Benzema regularly supplied from the left wing
📊 High percentage of own-team passes reflects Real's control of the match

METHODOLOGY

🐍 Python (requests, numpy, matplotlib)
📦 StatsBomb Open Data
🎨 Visualization: light green pitch, blue passing lines (thickness = pass volume), red nodes with player numbers

SUMMARY

Real Madrid won the final not only through individual brilliance, but primarily through a well-structured passing network. The left side + Toni Kroos = a tactical machine.
